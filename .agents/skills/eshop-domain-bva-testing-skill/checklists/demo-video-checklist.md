# Demo Video Checklist

Video demo quay end-to-end quá trình thực hiện một tính năng hoàn chỉnh bằng Agent Skill là thành phần bắt buộc để đạt điểm tối đa (10 điểm).

## 1. Kỹ Thuật Quay & Chất Lượng
- [ ] Độ phân giải tối thiểu: 720p (khuyên dùng 1080p).
- [ ] Âm thanh rõ ràng, không bị rè hoặc quá nhỏ. Có thuyết minh giọng nói hoặc phụ đề giải thích bằng tiếng Việt.
- [ ] Tốc độ video vừa phải, người xem có thể theo kịp các thao tác trên màn hình.

## 2. Nội Dung Video (End-to-End Flow)
- [ ] **Giới thiệu (0 - 30s):** Giới thiệu họ tên, MSSV, tính năng demo (ví dụ: FR-07 Shopping cart) và giới thiệu sơ bộ về Agent Skill `eshop-domain-bva-testing-skill`.
- [ ] **Kích hoạt Skill (30s - 2m):** Show file `feature-input-template.md` đã điền thông tin và quay cảnh gõ lệnh/nhập prompt để đánh thức Agent thực hiện phân tích.
- [ ] **Review Test Cases (2m - 4m):** Quay cảnh duyệt qua bộ test case Domain và BVA do AI sinh ra. Chỉ ra ít nhất một điểm bạn (sinh viên) đã chỉnh sửa, bổ sung (thể hiện vai trò con người trong AI-first).
- [ ] **Thực Thi & Báo Lỗi (4m - 7m):**
  - [ ] Thực hiện chạy thử một vài test case (Happy Path và Bug Path) trên giao diện EShop.
  - [ ] Quay cảnh phát hiện lỗi thực tế trên giao diện/API.
  - [ ] Quay cảnh tạo file báo cáo lỗi Markdown.
  - [ ] Quay cảnh chạy command đẩy lỗi lên GitHub Issues (hoặc tạo thủ công trên web).
- [ ] **AI Audit & Critique (7m - 9m):** Show file nhật ký `ai-audit-report.md` và đọc qua phần đánh giá tự phê bình `ai-critique.md`.
- [ ] **Kết Luận (9m - 10m):** Show file `README.md` với bảng tự đánh giá điểm số và kết thúc video.

## 3. Chia Sẻ Video
- [ ] Đã upload video lên YouTube (ở chế độ Không công khai - Unlisted hoặc Công khai - Public) hoặc Google Drive công khai.
- [ ] Link video đã được nhúng vào file `README.md` và báo cáo chính xác chưa?
- [ ] Kiểm tra xem link video có mở được bằng trình duyệt ẩn danh (Incognito) để tránh lỗi phân quyền truy cập không.
