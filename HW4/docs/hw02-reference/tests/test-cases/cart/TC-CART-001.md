# TC-CART-001: Hiển thị trạng thái giỏ hàng trống

## Requirement ID
FR-07

## Module / Test type / Technique
Cart / Functional / State Testing

## Preconditions
- Người dùng đã đăng nhập vào hệ thống.
- Giỏ hàng của người dùng đang trống (không có sản phẩm nào).

## Test data
| Tham số | Giá trị thử nghiệm |
| :--- | :--- |
| Không có | |

## Test steps
1. Truy cập vào trang giỏ hàng bằng cách nhấp vào liên kết/biểu tượng 'Giỏ hàng' trên thanh điều hướng hoặc truy cập đường dẫn `/cart`.
2. Quan sát giao diện hiển thị của trang.

## Expected result
- Trang giỏ hàng hiển thị thông báo rõ ràng: 'Giỏ hàng của bạn đang trống' hoặc nội dung tương đương.

Not Run / None
