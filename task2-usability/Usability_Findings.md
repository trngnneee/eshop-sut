## Severity model

| Severity | Operational definition |
| :--- | :--- |
| S1 — Blocker | Prevents task completion; no reasonable independent recovery |
| S2 — Serious | Requires moderator help or causes serious confusion/error |
| S3 — Moderate | Causes meaningful delay, repeated action, or hesitation |
| S4 — Minor | Small friction, cosmetic concern, or brief recoverable confusion |

Severity is assigned from impact and recovery, not frequency alone. A one-person blocker can be S1; a frequent visual complaint can remain S4.
