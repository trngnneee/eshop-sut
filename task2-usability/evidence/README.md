# Evidence Folder

This folder contains only genuine technical-preflight, pilot, and session evidence.

Recommended layout:

```text
evidence/
├── technical-preflight/
├── pilot/
├── P01/
├── P02/
├── P03/
├── P04/
├── P05/
├── P06/
└── P07/
```

Use participant IDs only. Never store unmasked contact details, real passwords, personal addresses, or unrelated notifications in this folder.
