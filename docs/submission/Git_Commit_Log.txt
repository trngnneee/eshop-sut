LỊCH SỬ GIT COMMIT (GIT COMMIT LOG)

Tài liệu này ghi lại nhật ký commit git tương ứng với từng bước trong quy trình kiểm thử bài tập HW03.
(Sinh viên có thể xuất lịch sử commit thực tế bằng lệnh `git log --oneline > docs/submission/Git_Commit_Log.txt` hoặc điền mẫu bên dưới).

Yêu cầu commit tương ứng với từng bước:
- Thiết kế GUI checklist (checklist design)
- Thực thi checklist (checklist execution)
- Log lỗi lên GitHub (bug logging)
- Từng phiên kiểm thử Usability (each usability session - 7 sessions)
- Phân tích kết quả Usability (usability analysis)
