# TC-FR11-02 - Mỗi dòng đơn hiển thị đủ trường bắt buộc

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Passed |
| Tiền điều kiện | User chính đã đăng nhập và có dữ liệu đơn hàng. |
| Dữ liệu kiểm thử | data/fr11.json: required_columns |

## Các Bước

1. Mở trang `/profile`.
2. Kiểm tra header bảng lịch sử đơn hàng.
3. Kiểm tra từng dòng dữ liệu đơn hàng.

## Kết Quả Mong Đợi

Bảng có các cột mã đơn, ngày đặt, tổng tiền và trạng thái; mỗi dòng có đầy đủ dữ liệu ở các cột bắt buộc.

## Assertion Gợi Ý

- Các header trong `expectedHeaders` hiển thị.
- Mỗi dòng có ít nhất 4 ô dữ liệu bắt buộc.
- Không có ô bắt buộc rỗng.
