# TC-FR11-09 - Trạng thái canceled được dịch tiếng Việt và có màu riêng

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | User chính có một đơn trạng thái `canceled`. |
| Dữ liệu kiểm thử | data/fr11.json: status_canceled |

## Các Bước

1. Đăng nhập bằng user chính.
2. Mở `/profile`.
3. Tìm dòng đơn có trạng thái `canceled`.
4. Kiểm tra nhãn và màu trạng thái.

## Kết Quả Mong Đợi

Trạng thái hiển thị là `Đã hủy` và có style nhóm màu đỏ.

## Assertion Gợi Ý

- Status badge có text `Đã hủy`.
- Class badge chứa `bg-red-100`.
- Class badge chứa `text-red-800`.
