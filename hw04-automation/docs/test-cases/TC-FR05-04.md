# TC-FR05-04 - Search by exact product name

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Positive |
| Priority | High |
| Status | Not Run |
| Preconditions | Homepage is open. |
| Test Data | data/fr05.json: exact_match |

## Steps

1. Enter an exact product name in the search input.
2. Submit the search form.
3. Observe the product grid and search summary.

## Expected Result

Only the matching product is shown, and the search summary displays the submitted keyword.

## Suggested Assertions

- Matching product is visible.
- Non-matching seeded products are not visible.
- Search summary contains the submitted keyword.
