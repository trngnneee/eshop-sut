# TC-FR05-10 - Search keyword containing script does not execute

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Negative |
| Priority | Critical |
| Status | Not Run |
| Preconditions | Homepage is open. |
| Test Data | data/fr05.json: script_payload |

## Steps

1. Register a browser dialog listener.
2. Enter a script payload in the search input.
3. Submit the search form.
4. Observe whether any script side effect occurs.

## Expected Result

The script is not executed and the page remains usable.

## Suggested Assertions

- No alert/dialog is triggered.
- Page remains on the homepage.
- Search summary treats the payload as text.
