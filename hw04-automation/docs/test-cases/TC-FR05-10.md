# TC-FR05-10 - Từ khóa chứa script không được thực thi

| Trường | Giá trị |
|---|---|
| Tính năng | FR-05 - Xem danh sách và tìm kiếm sản phẩm |
| Loại | Tiêu cực |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Trang chủ đang mở. |
| Dữ liệu kiểm thử | data/fr05.json: script_payload |

## Các Bước

1. Đăng ký listener để phát hiện browser dialog.
2. Nhập payload script vào ô tìm kiếm.
3. Gửi form tìm kiếm.
4. Quan sát có dialog hoặc side effect nào xảy ra không.

## Kết Quả Mong Đợi

Script không được thực thi và trang vẫn sử dụng bình thường.

## Assertion Gợi Ý

- Không có alert/dialog nào được kích hoạt.
- Trang vẫn ở trang chủ.
- Phần tóm tắt tìm kiếm hiển thị payload như văn bản thường.
