# TC-FR19-01 - Admin xem được bảng quản lý người dùng

| Trường | Giá trị |
|---|---|
| Tính năng | FR-19 - Quản lý người dùng admin |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Backend/admin frontend đang chạy; tài khoản admin seed tồn tại. |
| Dữ liệu kiểm thử | data/fr19.json: ui_admin_user_list |

## Các Bước

1. Đăng nhập admin bằng tài khoản trong data file.
2. Mở tab "Người dùng".
3. Chờ request `GET /api/admin/users` hoàn tất.

## Kết Quả Mong Đợi

Heading quản lý người dùng hiển thị và bảng user có ít nhất 2 dòng seed.

## Assertion Gợi Ý

- Heading `expectedHeading` hiển thị.
- Bảng user hiển thị.
- Số dòng user lớn hơn hoặc bằng `expectedMinimumRows`.
