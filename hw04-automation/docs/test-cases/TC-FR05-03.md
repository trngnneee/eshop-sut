# TC-FR05-03 - Product price is formatted with thousands separator and currency

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Positive |
| Priority | Medium |
| Status | Not Run |
| Preconditions | Homepage has loaded products. |
| Test Data | data/fr05.json: price_format |

## Steps

1. Open the homepage.
2. Locate known product prices.
3. Check the visible price text.

## Expected Result

Prices are shown with thousands separators and a currency unit.

## Suggested Assertions

- Known price text matches the expected formatted value.
- Price text includes the configured currency unit.
