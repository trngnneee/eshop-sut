# TC-FR11-12 - API lịch sử đơn hàng từ chối request không có token

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tiêu cực |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Không gửi header Authorization. |
| Dữ liệu kiểm thử | data/fr11.json: api_without_token |

## Các Bước

1. Gọi `GET /api/orders/my-orders` không có token.
2. Kiểm tra status code và body response.

## Kết Quả Mong Đợi

API trả `401 Unauthorized` và không trả danh sách đơn hàng.

## Assertion Gợi Ý

- Response status bằng `401`.
- Body có error `Unauthorized`.
- Body không phải array danh sách đơn hàng.
