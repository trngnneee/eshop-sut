# TC-FR19-09 - API list user từ chối token không hợp lệ

| Trường | Giá trị |
|---|---|
| Tính năng | FR-19 - Quản lý người dùng admin |
| Loại | Tiêu cực |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Có token sai hoặc không verify được. |
| Dữ liệu kiểm thử | data/fr19.json: api_invalid_token |

## Các Bước

1. Gọi `GET /api/admin/users` với token sai trong data file.

## Kết Quả Mong Đợi

API trả 403 Forbidden và không trả danh sách user.

## Assertion Gợi Ý

- Response status bằng `expectedStatus`.
- Error text chứa `expectedError`.
