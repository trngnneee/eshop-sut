# TC-FR05-12 - Product images have descriptive alt text

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Accessibility |
| Priority | Medium |
| Status | Not Run |
| Preconditions | Homepage has loaded products. |
| Test Data | data/fr05.json: all_products |

## Steps

1. Open the homepage.
2. Inspect all product images.

## Expected Result

Every product image has non-empty descriptive alt text.

## Suggested Assertions

- Every product image has an `alt` attribute.
- No product image has an empty `alt` value.
