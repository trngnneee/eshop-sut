# TC-FR05-12 - Ảnh sản phẩm có alt text mô tả

| Trường | Giá trị |
|---|---|
| Tính năng | FR-05 - Xem danh sách và tìm kiếm sản phẩm |
| Loại | Khả năng truy cập |
| Độ ưu tiên | Trung bình |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Trang chủ đã tải xong danh sách sản phẩm. |
| Dữ liệu kiểm thử | data/fr05.json: all_products |

## Các Bước

1. Mở trang chủ.
2. Kiểm tra tất cả ảnh sản phẩm.

## Kết Quả Mong Đợi

Mỗi ảnh sản phẩm có `alt` khác rỗng và mô tả đúng sản phẩm.

## Assertion Gợi Ý

- Mỗi ảnh sản phẩm có thuộc tính `alt`.
- Không có ảnh sản phẩm nào có `alt` rỗng.
- Giá trị `alt` tương ứng với tên hoặc mô tả sản phẩm.
