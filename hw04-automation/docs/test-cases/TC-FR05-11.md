# TC-FR05-11 - Payload kiểu SQL injection không được trả về dữ liệu ngoài phạm vi tìm kiếm

| Trường | Giá trị |
|---|---|
| Tính năng | FR-05 - Xem danh sách và tìm kiếm sản phẩm |
| Loại | Tiêu cực |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Trang chủ đang mở. |
| Dữ liệu kiểm thử | data/fr05.json: sql_payload |

## Các Bước

1. Nhập payload kiểu SQL injection vào ô tìm kiếm.
2. Gửi form tìm kiếm.
3. Quan sát danh sách sản phẩm trả về và trạng thái API.

## Kết Quả Mong Đợi

API không lỗi và không trả về toàn bộ sản phẩm ngoài hành vi tìm kiếm mong đợi.

## Assertion Gợi Ý

- Response thành công hoặc được xử lý lỗi một cách an toàn.
- Danh sách sản phẩm không bị mở rộng bất thường thành toàn bộ sản phẩm.
- Không render HTML lỗi database trên giao diện.
