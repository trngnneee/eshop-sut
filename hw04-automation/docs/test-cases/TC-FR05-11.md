# TC-FR05-11 - SQL injection style payload does not expose unrelated products

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Negative |
| Priority | Critical |
| Status | Not Run |
| Preconditions | Homepage is open. |
| Test Data | data/fr05.json: sql_payload |

## Steps

1. Enter a SQL injection-style payload in the search input.
2. Submit the search form.
3. Observe the returned product list and API response behavior.

## Expected Result

The API does not error and does not return products outside the intended search behavior.

## Suggested Assertions

- Response status is successful or gracefully handled.
- Product list does not expand unexpectedly to all products.
- No database error HTML is rendered.
