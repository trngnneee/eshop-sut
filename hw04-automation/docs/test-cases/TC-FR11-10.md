# TC-FR11-10 - User không thấy đơn hàng của user khác

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Bảo mật |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | User chính và user phụ đều có đơn hàng riêng. |
| Dữ liệu kiểm thử | data/fr11.json: other_user_isolation |

## Các Bước

1. Đăng nhập bằng user chính.
2. Mở `/profile`.
3. Lấy danh sách đơn của user chính qua `GET /api/orders/my-orders`.
4. Kiểm tra UI không chứa dữ liệu đặc trưng của user phụ.

## Kết Quả Mong Đợi

Không có mã đơn hoặc tổng tiền đặc trưng của user phụ xuất hiện trong lịch sử user chính.

## Assertion Gợi Ý

- Response API của user chính không chứa đơn của user phụ.
- Bảng UI không chứa `forbiddenAmountText`.
- Không có dòng nào map tới order id của user phụ.
