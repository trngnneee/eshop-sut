# TC-FR19-07 - Admin không được tự xóa tài khoản đang đăng nhập

| Trường | Giá trị |
|---|---|
| Tính năng | FR-19 - Quản lý người dùng admin |
| Loại | Bảo mật |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Admin đã đăng nhập và xác định được id của chính admin. |
| Dữ liệu kiểm thử | data/fr19.json: self_delete_blocked |

## Các Bước

1. Đăng nhập admin.
2. Lấy id admin hiện tại từ danh sách user.
3. Gọi `DELETE /api/admin/users/{adminId}` bằng token admin.
4. Lấy lại danh sách user.

## Kết Quả Mong Đợi

Request tự xóa bị từ chối và admin hiện tại vẫn tồn tại.

## Assertion Gợi Ý

- Delete response status bằng `expectedStatus`.
- Danh sách user sau đó vẫn chứa email admin.
