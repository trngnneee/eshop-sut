# TC-FR19-03 - API list user không trả về password

| Trường | Giá trị |
|---|---|
| Tính năng | FR-19 - Quản lý người dùng admin |
| Loại | Bảo mật |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Passed |
| Tiền điều kiện | Có token admin hợp lệ. |
| Dữ liệu kiểm thử | data/fr19.json: api_list_excludes_password |

## Các Bước

1. Đăng nhập admin để lấy token.
2. Gọi `GET /api/admin/users` với token admin.
3. Kiểm tra từng object user trong JSON response.

## Kết Quả Mong Đợi

API trả status 200 và không user object nào có field `password`.

## Assertion Gợi Ý

- Response status bằng `expectedStatus`.
- Body là array.
- Mỗi user object không có các key trong `forbiddenFields`.
