# TC-FR11-11 - Chưa đăng nhập không xem được lịch sử đơn hàng qua UI

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tiêu cực |
| Độ ưu tiên | Cao |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Local storage không có token. |
| Dữ liệu kiểm thử | data/fr11.json: unauthenticated_profile |

## Các Bước

1. Xóa token khỏi localStorage.
2. Mở trang `/profile`.
3. Quan sát nội dung trang.

## Kết Quả Mong Đợi

Trang hiển thị thông báo yêu cầu đăng nhập và không hiển thị bảng lịch sử đơn hàng.

## Assertion Gợi Ý

- Text `Vui lòng đăng nhập` hiển thị.
- Heading `Lịch sử đơn hàng` không hiển thị.
- Không có bảng lịch sử đơn hàng.
