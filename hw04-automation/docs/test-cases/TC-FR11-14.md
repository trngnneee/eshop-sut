# TC-FR11-14 - User chưa có đơn hàng thấy empty state phù hợp

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Biên |
| Độ ưu tiên | Trung bình |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | User rỗng đơn đã đăng nhập và chưa checkout. |
| Dữ liệu kiểm thử | data/fr11.json: empty_order_history |

## Các Bước

1. Đăng nhập bằng user chưa có đơn hàng.
2. Mở trang `/profile`.
3. Chờ request `GET /api/orders/my-orders` hoàn tất.
4. Quan sát khu vực lịch sử đơn hàng.

## Kết Quả Mong Đợi

Không hiển thị bảng đơn hàng; hiển thị thông báo `Bạn chưa có đơn hàng nào.`

## Assertion Gợi Ý

- Text empty state hiển thị đúng.
- Không có dòng dữ liệu đơn hàng.
- API trả mảng rỗng cho user này.
