# TC-FR19-11 - User thường không được xóa user

| Trường | Giá trị |
|---|---|
| Tính năng | FR-19 - Quản lý người dùng admin |
| Loại | Bảo mật |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Có actor role user và target user để bảo vệ. |
| Dữ liệu kiểm thử | data/fr19.json: api_non_admin_delete_forbidden |

## Các Bước

1. Tạo actor user thường và protected target user.
2. Đăng nhập actor user thường.
3. Gọi `DELETE /api/admin/users/{targetId}` bằng token actor.
4. Kiểm tra target user vẫn tồn tại bằng token admin.

## Kết Quả Mong Đợi

API trả 403 Forbidden và target user không bị xóa.

## Assertion Gợi Ý

- Delete response status bằng `expectedStatus`.
- Danh sách admin sau đó vẫn chứa protected target email.
