# TC-FR05-15 - Payload image onerror không được render hoặc thực thi

| Trường | Giá trị |
|---|---|
| Tính năng | FR-05 - Xem danh sách và tìm kiếm sản phẩm |
| Loại | Bảo mật/biên |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Trang chủ đang mở. |
| Dữ liệu kiểm thử | data/fr05.json: image_onerror_payload |

## Các Bước

1. Nhập payload `<image src=1 href=1 onerror="javascript:alert(1)"></image>` vào ô tìm kiếm.
2. Gửi form tìm kiếm.
3. Quan sát browser dialog và phần tóm tắt từ khóa tìm kiếm.
4. Kiểm tra DOM trong phần summary.

## Kết Quả Mong Đợi

Payload phải được hiển thị như văn bản thường. Trình duyệt không được mở dialog `alert(1)`, và không có element `image` hoặc `img[src="1"]` được chèn vào DOM.

## Assertion Gợi Ý

- Không xuất hiện dialog có text `1`.
- `searchSummary` chứa payload dưới dạng text.
- `searchSummary.locator("image")` có count bằng 0.
- `searchSummary.locator('img[src="1"]')` có count bằng 0.
