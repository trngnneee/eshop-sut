# TC-FR05-01 - Display all products on homepage

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Positive |
| Priority | High |
| Status | Not Run |
| Preconditions | Backend and frontend are running; seed products exist. |
| Test Data | data/fr05.json: all_products |

## Steps

1. Open the web homepage.
2. Wait for the product API request to finish.
3. Observe the product grid.

## Expected Result

The product grid is visible and contains the seeded products.

## Suggested Assertions

- Product grid container is visible.
- Expected seeded product names are visible.
- Product count text, if present, matches the number of displayed cards.
