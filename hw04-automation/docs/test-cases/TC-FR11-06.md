# TC-FR11-06 - Trạng thái confirmed được dịch tiếng Việt và có màu riêng

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | User chính có một đơn trạng thái `confirmed`. |
| Dữ liệu kiểm thử | data/fr11.json: status_confirmed |

## Các Bước

1. Đăng nhập bằng user chính.
2. Mở `/profile`.
3. Tìm dòng đơn có trạng thái `confirmed`.
4. Kiểm tra nhãn và màu trạng thái.

## Kết Quả Mong Đợi

Trạng thái hiển thị là `Đã xác nhận` và có style nhóm màu indigo.

## Assertion Gợi Ý

- Status badge có text `Đã xác nhận`.
- Class badge chứa `bg-indigo-100`.
- Class badge chứa `text-indigo-800`.
