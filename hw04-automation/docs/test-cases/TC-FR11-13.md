# TC-FR11-13 - API lịch sử đơn hàng từ chối token không hợp lệ

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tiêu cực |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Gửi token sai định dạng hoặc không verify được. |
| Dữ liệu kiểm thử | data/fr11.json: api_invalid_token |

## Các Bước

1. Gọi `GET /api/orders/my-orders` với token không hợp lệ.
2. Kiểm tra status code và body response.

## Kết Quả Mong Đợi

API trả `403 Forbidden` và không trả danh sách đơn hàng.

## Assertion Gợi Ý

- Response status bằng `403`.
- Body có error `Forbidden`.
- Body không phải array danh sách đơn hàng.
