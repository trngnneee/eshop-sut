# TC-FR05-13 - Homepage has exactly one h1 element

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Semantic HTML |
| Priority | Medium |
| Status | Not Run |
| Preconditions | Homepage has loaded products. |
| Test Data | data/fr05.json: h1_rule |

## Steps

1. Open the homepage.
2. Count all `<h1>` elements in the document.

## Expected Result

Exactly one `<h1>` exists on the page.

## Suggested Assertions

- `page.locator("h1")` has count `1`.
- The single h1 is the page title.
