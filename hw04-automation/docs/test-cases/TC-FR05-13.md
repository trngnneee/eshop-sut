# TC-FR05-13 - Trang chủ chỉ có đúng một thẻ h1

| Trường | Giá trị |
|---|---|
| Tính năng | FR-05 - Xem danh sách và tìm kiếm sản phẩm |
| Loại | HTML ngữ nghĩa |
| Độ ưu tiên | Trung bình |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Trang chủ đã tải xong danh sách sản phẩm. |
| Dữ liệu kiểm thử | data/fr05.json: h1_rule |

## Các Bước

1. Mở trang chủ.
2. Đếm tất cả thẻ `<h1>` trong document.

## Kết Quả Mong Đợi

Trang chỉ có đúng một thẻ `<h1>`.

## Assertion Gợi Ý

- `page.locator("h1")` có count bằng `1`.
- Thẻ h1 duy nhất là tiêu đề chính của trang.
