# TC-FR05-05 - Search by partial product name

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Positive |
| Priority | High |
| Status | Not Run |
| Preconditions | Homepage is open. |
| Test Data | data/fr05.json: partial_match |

## Steps

1. Enter a partial product name in the search input.
2. Submit the search form.
3. Observe the product grid.

## Expected Result

All products whose names contain the keyword are shown.

## Suggested Assertions

- Expected matching products are visible.
- Products outside the expected match set are not visible.
