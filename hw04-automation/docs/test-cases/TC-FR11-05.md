# TC-FR11-05 - Trạng thái pending được dịch tiếng Việt và có màu riêng

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | User chính có một đơn trạng thái `pending`. |
| Dữ liệu kiểm thử | data/fr11.json: status_pending |

## Các Bước

1. Đăng nhập bằng user chính.
2. Mở `/profile`.
3. Tìm dòng đơn có trạng thái `pending`.
4. Kiểm tra nhãn và màu trạng thái.

## Kết Quả Mong Đợi

Trạng thái hiển thị là `Chờ xác nhận` và có style nhóm màu vàng.

## Assertion Gợi Ý

- Status badge có text `Chờ xác nhận`.
- Class badge chứa `bg-yellow-100`.
- Class badge chứa `text-yellow-800`.
