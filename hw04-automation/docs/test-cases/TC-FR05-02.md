# TC-FR05-02 - Product card shows required fields

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Positive |
| Priority | High |
| Status | Not Run |
| Preconditions | Homepage has loaded products. |
| Test Data | data/fr05.json: all_products |

## Steps

1. Open the homepage.
2. Inspect each visible product card.

## Expected Result

Each product card shows an image, product name, formatted price, detail button, and add-to-cart button.

## Suggested Assertions

- Each card has one image.
- Product name text is visible.
- Price text is visible.
- "Xem chi tiết" and "Thêm vào giỏ" actions are visible.
