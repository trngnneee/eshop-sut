# TC-FR19-13 - Xóa một user không ảnh hưởng user khác

| Trường | Giá trị |
|---|---|
| Tính năng | FR-19 - Quản lý người dùng admin |
| Loại | Biên |
| Độ ưu tiên | Cao |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Tạo 2 user mới: một target xóa và một protected user. |
| Dữ liệu kiểm thử | data/fr19.json: delete_one_user_preserves_others |

## Các Bước

1. Tạo target user và protected user.
2. Đăng nhập admin.
3. Xóa target user.
4. Refresh danh sách user.
5. Kiểm tra protected user.

## Kết Quả Mong Đợi

Chỉ target user biến mất; protected user vẫn tồn tại trong danh sách.

## Assertion Gợi Ý

- Target email không còn trong list.
- Protected email vẫn hiển thị trong list.
