# TC-FR05-14 - Loading state is visible while products are fetched

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Loading |
| Priority | Medium |
| Status | Not Run |
| Preconditions | Product API response can be delayed or intercepted by the automation script. |
| Test Data | data/fr05.json: delayed_api |

## Steps

1. Delay or intercept the product API response.
2. Open the homepage.
3. Observe the UI before the API response completes.
4. Let the API response continue.

## Expected Result

A loading indicator is visible while waiting for data, then the product grid appears after the response completes.

## Suggested Assertions

- Loading indicator is visible before the API response resolves.
- Loading indicator disappears after the API response resolves.
- Product grid is visible after loading completes.
