# TC-FR05-14 - Hiển thị loading khi đang tải dữ liệu sản phẩm

| Trường | Giá trị |
|---|---|
| Tính năng | FR-05 - Xem danh sách và tìm kiếm sản phẩm |
| Loại | Trạng thái tải |
| Độ ưu tiên | Trung bình |
| Trạng thái | Failed |
| Tiền điều kiện | Automation script có thể delay hoặc intercept response của API sản phẩm. |
| Dữ liệu kiểm thử | data/fr05.json: delayed_api |

## Các Bước

1. Delay hoặc intercept response của API sản phẩm.
2. Mở trang chủ.
3. Quan sát UI trước khi API trả response.
4. Cho API trả response bình thường.

## Kết Quả Mong Đợi

Loading indicator hiển thị trong lúc chờ dữ liệu, sau đó biến mất khi dữ liệu đã tải xong và lưới sản phẩm xuất hiện.

## Assertion Gợi Ý

- Loading indicator hiển thị trước khi response API hoàn tất.
- Loading indicator biến mất sau khi response API hoàn tất.
- Lưới sản phẩm hiển thị sau khi tải xong.
