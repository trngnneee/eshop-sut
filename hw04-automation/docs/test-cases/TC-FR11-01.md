# TC-FR11-01 - User đã đăng nhập xem được bảng lịch sử đơn hàng

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Backend/frontend đang chạy; user chính có ít nhất 3 đơn hàng. |
| Dữ liệu kiểm thử | data/fr11.json: primary_user_orders |

## Các Bước

1. Đăng nhập bằng user chính.
2. Mở trang `/profile`.
3. Chờ request `GET /api/orders/my-orders` hoàn tất.
4. Quan sát khu vực lịch sử đơn hàng.

## Kết Quả Mong Đợi

Khu vực "Lịch sử đơn hàng" hiển thị bảng đơn hàng và có ít nhất 3 dòng đơn của user chính.

## Assertion Gợi Ý

- Heading "Lịch sử đơn hàng" hiển thị.
- Bảng lịch sử đơn hàng hiển thị.
- Số dòng đơn hàng lớn hơn hoặc bằng `expectedMinimumRows`.
