# TC-FR19-14 - UI không hiển thị password

| Trường | Giá trị |
|---|---|
| Tính năng | FR-19 - Quản lý người dùng admin |
| Loại | Bảo mật |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Admin đã đăng nhập và mở tab Người dùng. |
| Dữ liệu kiểm thử | data/fr19.json: ui_no_password_visible |

## Các Bước

1. Mở tab "Người dùng".
2. Đọc header bảng user.
3. Đọc text trong body bảng user.

## Kết Quả Mong Đợi

Không có cột Password/Mật khẩu và không hiển thị giá trị password seed.

## Assertion Gợi Ý

- Header không chứa các text trong `forbiddenHeaderTexts`.
- Table body không chứa các password trong `forbiddenCellValues`.
