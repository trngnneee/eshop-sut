# TC-FR05-09 - Search keyword containing HTML is displayed safely

| Field | Value |
|---|---|
| Feature | FR-05 - Product listing and search |
| Type | Negative |
| Priority | Critical |
| Status | Not Run |
| Preconditions | Homepage is open. |
| Test Data | data/fr05.json: html_payload |

## Steps

1. Enter an HTML payload in the search input.
2. Submit the search form.
3. Inspect the rendered search summary.

## Expected Result

The payload is displayed as plain text. No injected HTML element is rendered.

## Suggested Assertions

- The literal payload text is visible.
- No element from the injected payload exists in the DOM.
