# TC-FR19-10 - User thường không được lấy danh sách user

| Trường | Giá trị |
|---|---|
| Tính năng | FR-19 - Quản lý người dùng admin |
| Loại | Bảo mật |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Có tài khoản role user và token hợp lệ của user đó. |
| Dữ liệu kiểm thử | data/fr19.json: api_non_admin_list_forbidden |

## Các Bước

1. Tạo/đăng nhập user thường.
2. Gọi `GET /api/admin/users` bằng token user thường.

## Kết Quả Mong Đợi

API trả 403 Forbidden và không trả dữ liệu user.

## Assertion Gợi Ý

- Response status bằng `expectedStatus`.
- Body không phải danh sách user thành công.
