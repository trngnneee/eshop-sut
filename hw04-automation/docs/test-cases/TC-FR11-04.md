# TC-FR11-04 - Tổng tiền hiển thị theo định dạng tiền tệ dễ đọc

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Passed |
| Tiền điều kiện | User chính có đơn với nhiều tổng tiền khác nhau. |
| Dữ liệu kiểm thử | data/fr11.json: amount_format |

## Các Bước

1. Đăng nhập bằng user chính.
2. Mở `/profile`.
3. Kiểm tra cột tổng tiền của các đơn trong dữ liệu kiểm thử.

## Kết Quả Mong Đợi

Tổng tiền được format có phân cách hàng nghìn, có đơn vị `₫`, và khớp `total_amount` từ API.

## Assertion Gợi Ý

- Tổng tiền chứa expected text trong `checks`.
- Tổng tiền có ký hiệu `₫`.
- Tổng tiền không chứa `VND`.
