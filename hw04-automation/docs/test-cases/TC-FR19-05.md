# TC-FR19-05 - Admin xóa được user thường

| Trường | Giá trị |
|---|---|
| Tính năng | FR-19 - Quản lý người dùng admin |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Passed |
| Tiền điều kiện | Tạo user thường mới dùng riêng cho việc xóa; admin đã đăng nhập. |
| Dữ liệu kiểm thử | data/fr19.json: delete_regular_user |

## Các Bước

1. Tạo target user bằng API register.
2. Đăng nhập admin.
3. Xóa target user qua UI hoặc `DELETE /api/admin/users/{id}`.

## Kết Quả Mong Đợi

Request xóa thành công với status 200 và message phù hợp.

## Assertion Gợi Ý

- Delete response status bằng `expectedDeleteStatus`.
- Response message chứa `expectedMessage`.
