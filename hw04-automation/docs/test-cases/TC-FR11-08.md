# TC-FR11-08 - Trạng thái delivered được dịch tiếng Việt và có màu riêng

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | User chính có một đơn trạng thái `delivered`. |
| Dữ liệu kiểm thử | data/fr11.json: status_delivered |

## Các Bước

1. Đăng nhập bằng user chính.
2. Mở `/profile`.
3. Tìm dòng đơn có trạng thái `delivered`.
4. Kiểm tra nhãn và màu trạng thái.

## Kết Quả Mong Đợi

Trạng thái hiển thị là `Đã giao` và có style nhóm màu xanh lá.

## Assertion Gợi Ý

- Status badge có text `Đã giao`.
- Class badge chứa `bg-green-100`.
- Class badge chứa `text-green-800`.
