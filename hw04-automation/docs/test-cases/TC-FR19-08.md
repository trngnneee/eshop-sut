# TC-FR19-08 - API list user từ chối request không token

| Trường | Giá trị |
|---|---|
| Tính năng | FR-19 - Quản lý người dùng admin |
| Loại | Tiêu cực |
| Độ ưu tiên | Nghiêm trọng |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | Không gửi Authorization header. |
| Dữ liệu kiểm thử | data/fr19.json: api_without_token |

## Các Bước

1. Gọi `GET /api/admin/users` không có token.

## Kết Quả Mong Đợi

API trả 401 Unauthorized và không trả danh sách user.

## Assertion Gợi Ý

- Response status bằng `expectedStatus`.
- Error text chứa `expectedError`.
