# TC-FR11-07 - Trạng thái shipping được dịch tiếng Việt và có màu riêng

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Chưa chạy |
| Tiền điều kiện | User chính có một đơn trạng thái `shipping`. |
| Dữ liệu kiểm thử | data/fr11.json: status_shipping |

## Các Bước

1. Đăng nhập bằng user chính.
2. Mở `/profile`.
3. Tìm dòng đơn có trạng thái `shipping`.
4. Kiểm tra nhãn và màu trạng thái.

## Kết Quả Mong Đợi

Trạng thái hiển thị là `Đang giao` và có style nhóm màu xanh dương.

## Assertion Gợi Ý

- Status badge có text `Đang giao`.
- Class badge chứa `bg-blue-100`.
- Class badge chứa `text-blue-800`.
