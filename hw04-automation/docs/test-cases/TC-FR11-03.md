# TC-FR11-03 - Mã đơn hiển thị theo đúng order id

| Trường | Giá trị |
|---|---|
| Tính năng | FR-11 - Xem lịch sử đơn hàng |
| Loại | Tích cực |
| Độ ưu tiên | Cao |
| Trạng thái | Passed |
| Tiền điều kiện | User chính có các đơn hàng đã setup qua API. |
| Dữ liệu kiểm thử | data/fr11.json: order_id_display |

## Các Bước

1. Đăng nhập bằng user chính.
2. Gọi hoặc chờ response `GET /api/orders/my-orders`.
3. Mở `/profile`.
4. So sánh mã đơn hiển thị trên UI với `id` trong response API.

## Kết Quả Mong Đợi

Mã đơn hiển thị theo dạng `#<id>` và khớp với order id trong API.

## Assertion Gợi Ý

- Cell mã đơn chứa prefix `#`.
- Text mã đơn bằng `#${order.id}`.
- Không có dòng đơn thiếu mã.
