## Title
[Minor] Firefox không log status code khi API trả 500 — UI cũng không báo gì, dev mất hoàn toàn dấu vết

## Description
Khi `/api/products/1` (hoặc `/api/orders/my-orders`) trả 500, UI kẹt ở `"Đang tải..."` / hiện sai empty state (đã báo ở checklist `GUI-IA04-09` / `GUI-IA04-16`, Fail trên mọi platform). Phần cross-platform nằm ở chỗ khác: **mức chẩn đoán còn lại trong console khác nhau theo engine**, và Firefox là nơi mất nhiều nhất.

## Steps to Reproduce
1. Chặn `**/api/products/1` trả HTTP 500 (harness dùng `page.route(...).fulfill({status:500})`).
2. Mở `http://localhost:5173/product/1`.
3. Đọc console.
4. Lặp lại trên 3 engine.

## Expected Result
UI hiện error state + nút thử lại; và ít nhất console phải cho biết request nào lỗi với status code.

## Actual Result
| Platform | Console |
|---|---|
| Chromium | 4 lỗi, gồm `"Failed to load resource: the server responded with a status of 500 (Internal Server Error)"` và `AxiosError: Request failed with status code 500` kèm stack |
| WebKit | 2 lỗi, cùng 2 nội dung trên nhưng không có stack |
| **Firefox** | 2 lỗi, chỉ `"Error"` và `"Lỗi lấy đơn hàng: Error"` — **không có status code, không có dòng resource** |

UI trống thông tin ở cả 3 engine.

## Environment
Như XP-01.

## Related checklist item(s)
GUI-IA04-09, GUI-IA04-16

## Requirement
FR-24 (error state / feedback) — phần cross-platform là rủi ro chẩn đoán, không phải yêu cầu trực tiếp

## Severity
Minor — không ảnh hưởng người dùng cuối (UI vốn đã không báo gì, đã tính ở bug Task 1), nhưng làm chậm chẩn đoán sự cố nếu chỉ có log từ Firefox.
