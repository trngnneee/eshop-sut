# Phiếu SUS (System Usability Scale)

---

## A. Bảng đối chiếu Anh–Việt (cho report / kiểm chứng)

"The system" được thay bằng "trang web mua sắm này". Giữ nguyên cấu trúc chuẩn SUS: câu lẻ = phát biểu tích cực, câu chẵn = phát biểu tiêu cực, thang 5 mức.

| # | Bản gốc (Brooke, 1996) | Bản dịch tiếng Việt | +/− |
|---|---|---|---|
| 1 | I think that I would like to use this system frequently. | Tôi nghĩ mình sẽ muốn sử dụng trang web mua sắm này thường xuyên. | + |
| 2 | I found the system unnecessarily complex. | Tôi thấy trang web mua sắm này phức tạp một cách không cần thiết. | − |
| 3 | I thought the system was easy to use. | Tôi thấy trang web mua sắm này dễ sử dụng. | + |
| 4 | I think that I would need the support of a technical person to be able to use this system. | Tôi nghĩ mình sẽ cần một người rành kỹ thuật hỗ trợ thì mới dùng được trang web mua sắm này. | − |
| 5 | I found the various functions in this system were well integrated. | Tôi thấy các chức năng trong trang web mua sắm này được kết hợp với nhau một cách nhịp nhàng. | + |
| 6 | I thought there was too much inconsistency in this system. | Tôi thấy trang web mua sắm này có quá nhiều điểm thiếu nhất quán. | − |
| 7 | I would imagine that most people would learn to use this system very quickly. | Tôi hình dung hầu hết mọi người sẽ học được cách dùng trang web mua sắm này rất nhanh. | + |
| 8 | I found the system very cumbersome to use. | Tôi thấy trang web mua sắm này rất rườm rà, vướng víu khi sử dụng. | − |
| 9 | I felt very confident using the system. | Tôi cảm thấy rất tự tin khi sử dụng trang web mua sắm này. | + |
| 10 | I needed to learn a lot of things before I could get going with this system. | Tôi đã phải mày mò tìm hiểu nhiều thứ thì mới bắt đầu dùng được trang web mua sắm này. | − |
