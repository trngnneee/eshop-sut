## Test steps
1. Mở trang quản lý đơn hàng trong Admin UI.
2. Tìm các đơn hàng có trạng thái `delivered` và `canceled`.
3. Quan sát các action button trong cột thao tác.
4. Không thực hiện request nếu UI không hiển thị action.
