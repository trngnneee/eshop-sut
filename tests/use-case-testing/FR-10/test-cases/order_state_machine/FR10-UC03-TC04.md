# FR10-UC03-TC04: Admin bị từ chối khi hủy đơn delivered

## Requirement ID
FR-10

## Module / Test type / Technique
Order State Machine / Functional / Use Case Testing

## Use case coverage
| Thuộc tính | Giá trị |
| :--- | :--- |
| Use case ID | UC-03 |
| Actor | admin |
| Goal | Hủy đơn hàng cho khách khi đơn còn ở trạng thái được phép hủy. |
| Flow type | Exception |
| Covered flow | UC-03-EXC-02 |
| Covered requirement | `delivered` và `canceled` là final states, không được phép chuyển tiếp. Source: README.md:141-162. |

## Preconditions
- Có đơn hàng hợp lệ đang ở trạng thái `delivered`.
- Admin đã đăng nhập.

## Test data
| Tham số | Giá trị thử nghiệm |
| :--- | :--- |
| Actor | admin |
| Interface | Admin API |
| Endpoint / UI flow | PUT /api/admin/orders/:id/status |
| Input / Payload | {"status":"canceled"} |
| Fixture | {delivered_order_id} |

## Test steps
1. Chuẩn bị đơn hàng ở trạng thái `delivered`.
2. Đăng nhập bằng tài khoản `admin`.
3. Gửi request cập nhật status `canceled`.
4. Tải lại đơn hàng sau khi request bị từ chối.

## Expected result
- Hệ thống trả về HTTP 400 với thông báo lỗi phù hợp.
- Trạng thái đơn hàng vẫn là `delivered`.
