# FR10-UC01-TC02: Admin chuyển đơn hàng confirmed sang shipping

## Requirement ID
FR-10

## Module / Test type / Technique
Order State Machine / Functional / Use Case Testing

## Use case coverage
| Thuộc tính | Giá trị |
| :--- | :--- |
| Use case ID | UC-01 |
| Actor | admin |
| Goal | Cập nhật tiến trình xử lý đơn hàng theo đúng state machine. |
| Flow type | Alternate |
| Covered flow | UC-01-ALT-01 |
| Covered requirement | FR-10 định nghĩa luồng `pending -> confirmed -> shipping -> delivered`. Source: README.md:141-162. |

## Preconditions
- Có đơn hàng hợp lệ đang ở trạng thái `confirmed`.
- Tài khoản `admin` đã đăng nhập.

## Test data
| Tham số | Giá trị thử nghiệm |
| :--- | :--- |
| Actor | admin |
| Interface | Admin API / Admin UI |
| Endpoint / UI flow | PUT /api/admin/orders/:id/status / Admin bấm Giao hàng |
| Input / Payload | {"status":"shipping"} |
| Fixture | {confirmed_order_id} |

## Test steps
1. Chuẩn bị đơn hàng ở trạng thái `confirmed`.
2. Đăng nhập bằng tài khoản `admin`.
3. Gửi request cập nhật status `shipping` hoặc bấm `Giao hàng` trên Admin UI.
4. Tải lại đơn hàng sau khi request hoàn tất.

## Expected result
- Hệ thống trả về HTTP 200 hoặc UI báo cập nhật thành công.
- Trạng thái đơn hàng chuyển từ `confirmed` sang `shipping`.
