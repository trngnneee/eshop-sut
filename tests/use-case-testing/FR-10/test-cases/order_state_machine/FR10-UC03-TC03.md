## Preconditions
- Có đơn hàng hợp lệ đang ở trạng thái `shipping`.
- Admin đã đăng nhập.

## Test data
| Tham số | Giá trị thử nghiệm |
| :--- | :--- |
| Actor | admin |
| Interface | Admin API |
| Endpoint / UI flow | PUT /api/admin/orders/:id/status |
| Input / Payload | {"status":"canceled"} |
| Fixture | {shipping_order_id} |

## Test steps
1. Chuẩn bị đơn hàng ở trạng thái `shipping`.
2. Đăng nhập bằng tài khoản `admin`.
3. Gửi request cập nhật status `canceled`.
4. Tải lại đơn hàng sau khi request bị từ chối.

## Expected result
- Hệ thống trả về HTTP 400 với thông báo lỗi phù hợp.
- Trạng thái đơn hàng vẫn là `shipping`.
