# FR10-UC01-TC01: Admin xác nhận đơn hàng pending

FR-10

| :--- | :--- |
| Use case ID | UC-01 |

| Goal | Cập nhật tiến trình xử lý đơn hàng theo đúng state machine. |

| Covered requirement | FR-10 định nghĩa luồng `pending -> confirmed -> shipping -> delivered`. Source: README.md:141-162. |

## Preconditions
- Có đơn hàng hợp lệ đang ở trạng thái `pending`.
- Tài khoản `admin` đã đăng nhập và có quyền cập nhật đơn hàng.

## Test data
| Tham số | Giá trị thử nghiệm |
| :--- | :--- |
| Actor | admin |
| Interface | Admin API / Admin UI |
| Endpoint / UI flow | PUT /api/admin/orders/:id/status / Admin bấm Xác nhận |
| Input / Payload | {"status":"confirmed"} |
| Fixture | {pending_order_id} |

## Test steps
1. Chuẩn bị một đơn hàng ở trạng thái `pending`.
2. Đăng nhập bằng tài khoản `admin`.
3. Gửi request `PUT /api/admin/orders/:id/status` với body `{"status":"confirmed"}` hoặc bấm `Xác nhận` trên Admin UI.
4. Tải lại chi tiết đơn hàng hoặc danh sách đơn hàng.

## Expected result
- Hệ thống trả về HTTP 200 hoặc UI báo cập nhật thành công.
- Trạng thái đơn hàng chuyển từ `pending` sang `confirmed`.
- Không có trường dữ liệu khác của đơn hàng bị thay đổi ngoài trạng thái.
