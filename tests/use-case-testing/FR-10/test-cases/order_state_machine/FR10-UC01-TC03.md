# FR10-UC01-TC03: Admin hoàn tất đơn hàng shipping sang delivered

## Requirement ID
FR-10

## Module / Test type / Technique
Order State Machine / Functional / Use Case Testing

## Use case coverage
| Thuộc tính | Giá trị |
| :--- | :--- |
| Use case ID | UC-01 |
| Actor | admin |
| Goal | Cập nhật tiến trình xử lý đơn hàng theo đúng state machine. |
| Flow type | Alternate |
| Covered flow | UC-01-ALT-02 |
| Covered requirement | FR-10 định nghĩa luồng `pending -> confirmed -> shipping -> delivered`. Source: README.md:141-162. |

## Preconditions
- Có đơn hàng hợp lệ đang ở trạng thái `shipping`.
- Tài khoản `admin` đã đăng nhập.

## Test data
| Tham số | Giá trị thử nghiệm |
| :--- | :--- |
| Actor | admin |
| Interface | Admin API / Admin UI |
| Endpoint / UI flow | PUT /api/admin/orders/:id/status / Admin bấm Hoàn thành |
| Input / Payload | {"status":"delivered"} |
| Fixture | {shipping_order_id} |

## Test steps
1. Chuẩn bị đơn hàng ở trạng thái `shipping`.
2. Đăng nhập bằng tài khoản `admin`.
3. Gửi request cập nhật status `delivered` hoặc bấm `Hoàn thành` trên Admin UI.
4. Tải lại đơn hàng sau khi request hoàn tất.

## Expected result
- Hệ thống trả về HTTP 200 hoặc UI báo cập nhật thành công.
- Trạng thái đơn hàng chuyển từ `shipping` sang `delivered`.
- Sau khi delivered, đơn hàng trở thành final state.
