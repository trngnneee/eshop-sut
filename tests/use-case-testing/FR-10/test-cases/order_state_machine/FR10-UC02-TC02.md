## Test steps
1. Chuẩn bị đơn hàng của user hiện tại ở trạng thái `confirmed`.
2. Đăng nhập bằng tài khoản `user`.
3. Bấm `Hủy đơn` hoặc gửi request hủy đơn.
4. Tải lại lịch sử đơn hàng.

## Expected result
- Hệ thống trả về HTTP 200 hoặc UI báo hủy thành công.
- Trạng thái đơn hàng chuyển sang `canceled`.
