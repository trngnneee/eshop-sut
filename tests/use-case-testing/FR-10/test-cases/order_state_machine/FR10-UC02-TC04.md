## Test steps
1. Chuẩn bị đơn hàng của user hiện tại ở trạng thái `shipping`.
2. Đăng nhập bằng tài khoản `user`.
3. Gửi request `PUT /api/orders/:id/cancel`.
4. Tải lại đơn hàng sau khi request bị từ chối.

## Expected result
- Hệ thống trả về HTTP 400 với thông báo lỗi phù hợp.
- Trạng thái đơn hàng vẫn là `shipping`.
