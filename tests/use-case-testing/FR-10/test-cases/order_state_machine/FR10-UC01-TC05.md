# FR10-UC01-TC05: Admin bị từ chối khi chuyển final state canceled sang delivered

FR-10

## Module / Test type / Technique
Order State Machine / Functional / Use Case Testing

| :--- | :--- |

| Goal | Cập nhật tiến trình xử lý đơn hàng theo đúng state machine. |

## Preconditions
- Có đơn hàng hợp lệ đang ở trạng thái `canceled`.
- Tài khoản `admin` đã đăng nhập.

## Test data
| Tham số | Giá trị thử nghiệm |
| :--- | :--- |
| Actor | admin |
| Interface | Admin API |
| Endpoint / UI flow | PUT /api/admin/orders/:id/status |
| Input / Payload | {"status":"delivered"} |
| Fixture | {canceled_order_id} |

## Test steps
1. Chuẩn bị đơn hàng ở trạng thái `canceled`.
2. Đăng nhập bằng tài khoản `admin`.
3. Gửi request cập nhật status thành `delivered`.
4. Tải lại đơn hàng sau khi request bị từ chối.

## Expected result
- Hệ thống trả về HTTP 400 với thông báo lỗi phù hợp.
- Trạng thái đơn hàng vẫn là `canceled` vì đây là final state.
