## Preconditions
- Có đơn hàng thuộc user hiện tại đang ở trạng thái `pending`.
- User đã đăng nhập trên Web hoặc gọi API với token hợp lệ.

## Test steps
1. Chuẩn bị đơn hàng của user hiện tại ở trạng thái `pending`.
2. Đăng nhập bằng tài khoản `user`.
3. Bấm `Hủy đơn` trên Web hoặc gửi request `PUT /api/orders/:id/cancel`.
4. Tải lại lịch sử đơn hàng của user.

## Expected result
- Hệ thống trả về HTTP 200 hoặc UI báo hủy thành công.
- Trạng thái đơn hàng chuyển sang `canceled`.
- Đơn hàng vẫn thuộc user hiện tại.
