FR-10

## Preconditions
- Có đơn hàng thuộc user hiện tại đang ở trạng thái `delivered`.
- User đã đăng nhập.

| Tham số | Giá trị thử nghiệm |

| Actor | user |
| Interface | API |
| Endpoint / UI flow | PUT /api/orders/:id/cancel |
| Input / Payload | {} |
| Fixture | {own_delivered_order_id} |

## Test steps
1. Chuẩn bị đơn hàng ở trạng thái `delivered`.
2. Đăng nhập bằng tài khoản `user`.
3. Gửi request hủy đơn.
4. Tải lại đơn hàng sau khi request bị từ chối.

## Expected result
- Hệ thống trả về HTTP 400 với thông báo lỗi phù hợp.
- Trạng thái đơn hàng vẫn là `delivered`.
