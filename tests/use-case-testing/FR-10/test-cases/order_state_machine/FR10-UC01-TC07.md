## Test steps
1. Đăng nhập bằng tài khoản `user` thường.
2. Gửi request `PUT /api/admin/orders/:id/status` với body `{"status":"confirmed"}`.
3. Tải lại đơn hàng sau khi request bị từ chối.

## Expected result
- Hệ thống trả về HTTP 401 hoặc 403.
- Trạng thái đơn hàng vẫn là `pending`.
