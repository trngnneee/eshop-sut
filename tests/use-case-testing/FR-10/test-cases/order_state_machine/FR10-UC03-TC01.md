## Test steps
1. Chuẩn bị đơn hàng ở trạng thái `pending`.
2. Đăng nhập bằng tài khoản `admin`.
3. Gửi request cập nhật status `canceled` hoặc bấm `Hủy` trên Admin UI.
4. Tải lại danh sách đơn hàng.

## Expected result
- Hệ thống trả về HTTP 200 hoặc UI báo cập nhật thành công.
- Trạng thái đơn hàng chuyển sang `canceled`.
