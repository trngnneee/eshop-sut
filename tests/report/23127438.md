## Domain Testing Report

### 1. Phương pháp Domain Testing

Domain Testing được áp dụng bằng cách phân tách từng input, state hoặc điều kiện quyền truy cập thành các phân vùng tương đương. Mỗi phân vùng hợp lệ được kiểm thử tối thiểu một lần; mỗi phân vùng không hợp lệ hoặc rủi ro bảo mật được kiểm thử bằng test case riêng để tránh một lỗi che lấp lỗi khác.

Với các chức năng dạng state machine như FR-10 và FR-18, mỗi transition hợp lệ/không hợp lệ được xem như một domain class riêng. Với các chức năng UI/API có dữ liệu người dùng như FR-04 và FR-20, domain class bao gồm cả dữ liệu hợp lệ, dữ liệu sai định dạng, dữ liệu rỗng, dữ liệu vượt quyền và dữ liệu có payload bảo mật.

## Boundary Value Analysis Report

### 1. Phương pháp BVA

Boundary Value Analysis được áp dụng cho các input có giới hạn độ dài hoặc giá trị số. Các giá trị biên được chọn theo nhóm `Min-1`, `Min`, `Min+1`, `Nominal`, `Max-1`, `Max`, `Max+1` khi có đủ min/max. Với `order_id`, đặc tả chỉ cho phép suy ra biên dưới là số nguyên dương, nên BVA chỉ xét `0`, `1`, `2`.
